Task 19: Filter Dataset Records

## Internship
Veda Technology – AI & ML Internship

## Objective
To learn how to filter records from a dataset using Pandas conditions.

## Tools Used
- Python
- Pandas
- Jupyter Notebook

## Concepts Covered
- DataFrame filtering
- Boolean conditions
- AND (`&`) operator
- OR (`|`) operator
- Multiple filtering conditions
- Counting filtered records

## Examples
1. Filter students scoring above 80.
2. Filter students belonging to the CSE department.
3. Filter students scoring above 70 and belonging to CSE.
4. Apply multiple conditions using AND and OR.

## Learning Outcome
Learned how to retrieve relevant records from datasets using Pandas filtering techniques.
